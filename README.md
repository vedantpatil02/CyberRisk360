# CyberRisk360

CyberRisk360 is a Cyber Risk Management and Governance, Risk & Compliance (GRC) platform designed to help organizations manage assets, vulnerabilities, risks, compliance controls, and remediation activities.

## Features

* User Authentication
* Asset Inventory Management
* Risk Register
* Vulnerability Management
* Compliance Mapping
* Dashboard & Reporting

## Technology Stack

### Backend

* FastAPI
* SQLAlchemy
* SQLite

### Frontend

* React
* Tailwind CSS

### Authentication

* JWT Tokens
* Role-Based Access Control (Planned)
